# Beta 使用者測試工具包

最後更新：2026-11-16（初版，測試前請指導教師過目）

## 1. 目的與要回答的問題

- 使用者能否靠這個 Agent 找到「下一本要讀的書」
- 使用者能否說出推薦的依據，並找到出處
- 使用者實際會怎麼問（用字、錯字、中英夾雜），用來改善問句理解

通過門檻（測試前設定，結果不論高低都照實記錄）：5 位受測者中至少 4 位完成任務一，並能說出推薦依據

## 2. 對象與規模

- 人數：5 位
- 來源：攝影社社員、修過或正在修攝影相關課程的學生、研究生
- 條件：讀過至少一本攝影理論或攝影史的書；沒有也可以參加，任務一改用指定書目
- 時間：每人約 30 分鐘，一對一，可線上或實體

## 3. 招募訊息（可直接貼）

> 我在做一個攝影理論的閱讀推薦工具「觀看的坐標」，想請你花 30 分鐘試用並給回饋。你只需要用它問幾個問題，我會在旁邊記錄你怎麼用、哪裡卡住。不會錄影，紀錄不含姓名。有興趣的話回我一個方便的時段，謝謝。

## 4. 開始前的說明與同意

開始前口頭說明以下四點，受測者同意後再開始：

- 這是測試工具，不是測試你；卡住代表工具需要改
- 我會記下你輸入的問句、完成與否和花費時間，不記姓名與聯絡方式
- 你可以隨時停止，也可以要求刪除你的紀錄
- 紀錄只用於改善這個專案與課程報告

## 5. 流程（約 30 分鐘）

| 時間 | 內容 |
|---|---|
| 3 分鐘 | 說明與同意；請受測者邊做邊說出想法 |
| 20 分鐘 | 三個任務，不提示操作方式；卡住超過 2 分鐘才給提示，並記錄 |
| 7 分鐘 | 三個訪談問題；填回饋表單 |

## 6. 三個任務

**任務一：找下一本書**

「你剛讀完一本攝影理論的書（自選；沒有的話用《觀看的方式》）。請用這個工具找出下一步要讀什麼，然後告訴我它為什麼這樣推薦。」

- 完成條件：說得出至少一項推薦，以及系統給的理由

**任務二：查核出處**

「從剛才的推薦裡選一項，找到它依據的原文引句和來源頁面，打開來源看看引句在不在。」

- 完成條件：找到引句與來源連結，並打開來源頁面

**任務三：問一個自己想知道的問題**

「問一個你自己真的想知道的攝影理論或攝影史問題，然後告訴我這個回答對你有沒有用。」

- 完成條件：無；記錄原始問句、系統是否答到重點、受測者的評價

## 7. 觀察紀錄表（每位受測者一份）

| 欄位 | 內容 |
|---|---|
| 編號 | P1 至 P5（不記姓名） |
| 背景 | 社團或系所、讀過的攝影理論書數量（0、1 至 3、4 以上） |
| 任務一 | 完成／未完成；花費時間；是否給過提示；說出的推薦依據 |
| 任務二 | 完成／未完成；花費時間；卡住的位置 |
| 任務三 | 原始問句（逐字）；系統是否答到重點；受測者評價 |
| 輸入的所有問句 | 逐字記錄，保留錯字與中英夾雜 |
| 異常 | 系統答非所問、查無資料、畫面看不懂之處 |

## 8. 訪談問題

1. 剛才的推薦，你會照著去讀嗎？為什麼？
2. 跟你平常找書的方式（問人、搜尋、問聊天 AI）比，這個工具哪裡比較好、哪裡比較差？
3. 如果只能改一個地方，你希望改什麼？

## 9. 回饋表單建議題目（Google 表單）

- 你找到下一本想讀的書了嗎？（有／沒有／不確定）
- 你看得懂推薦的理由嗎？（1 至 5 分）
- 你信任這個工具給的出處嗎？（1 至 5 分）
- 你之後還會想用嗎？（會／不會／看情況）
- 其他想說的（開放填答）

## 10. 測試後的整理

- 任務一、二的完成人數與花費時間
- 所有原始問句加入題庫，標記系統沒有理解的問句，作為問句理解的改善依據
- 訪談與表單的回饋依「推薦內容、出處呈現、問句理解、介面」分類
- 對照通過門檻，寫入評估結果文件
