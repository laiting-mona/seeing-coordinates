# 評估結果

問題集設計見 `docs/eval-design.md`。本檔記錄實跑結果;原始回答不進版控(`build/eval/`),可由下列指令重現。

```bash
python tools/eval_report.py           # → build/eval/eval_answers.xlsx(需 openpyxl)
```

## 我們的 Agent(2026-11-10,commit d3994e5)

| 指標 | 結果 |
|---|---|
| 題數 × 次數 | 1000 × 5 = 5000 次回答 |
| 五次回答完全相同 | **1000 / 1000**(修正前 968 / 1000,見 decision-log 2026-11-10) |
| 回答附至少一個查證網址 | 627 / 1000 |
| 解析不到任何節點 | 85 / 1000(主評估 24 / 400,穩健性 61 / 600) |
| 主評估:前兩個解析節點命中「涉及節點」 | 307 / 400(77%) |
| 主評估:意圖落到 default(沒有任何意圖關鍵字命中) | 226 / 400 |

穩健性檢驗:同一格裡,變體與源頭題的意圖相同且前兩個解析節點相同的比例。

| 變體 | 句型 | 與源頭一致 |
|---|---|---|
| S4 | 無標點(空格) | 97 / 100 |
| S5 | 無標點(句號) | 97 / 100 |
| S7 | 中英夾雜 | 57 / 100 |
| K3 | 僅關鍵字 + 含錯字 | 53 / 100 |
| S3 | 含錯字 | 45 / 100 |
| S6 | 多問句堆疊 | 45 / 100 |

初步讀法(尚未逐題人工評分):

- **可重現性是這個 Agent 和一般聊天機器人最大的差別**:同一題問五次,答案逐字相同;外部平台的五次回答預期會不同,這正是要對照的。
- **標點不影響,錯字和中英夾雜影響很大**:解析靠字串比對,「桑塔各」「社影」對不到節點,英文人名(Sontag、Barthes)目前只有部分在別名表裡。
- **多問句堆疊會改變意圖**:追問句常帶「出處」「哪本」等詞,把原本的 recommend 或 relation 搶成 provenance。
- **意圖覆蓋不足**:400 題主評估有 226 題沒有命中任何意圖關鍵字,退回「列出該節點的關係」;回答仍附出處,但沒有回應問題的形狀(比較、排書單、定義)。這是下一步要改的地方,改法照評估規則:補 `INTENT_KEYWORDS`、`ALIASES` 或新增 handler,不改資料遷就題目。

## 外部平台(Claude、ChatGPT、Gemini、Google AI Overview)
